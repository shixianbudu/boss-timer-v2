# Boss 刷新倒计时 2.0（联机同步版）

记录游戏 Boss 击杀时间的小工具：每条线点击一下即记录击杀时间并进入刷新倒计时，倒计时越接近刷新，卡片颜色从绿渐变到红，刷新后红色闪烁并可播放提示音。

**2.0 新特性：联机同步** —— 所有打开本页面的人共享同一份击杀记录，任何人记录了击杀，其他人的页面会在几秒内自动更新。

## Boss 配置

| Boss | 刷新周期 |
| --- | --- |
| 蜗牛王 / 树妖王 | 45 分钟 |
| 巨居蟹 | 20 分钟 |
| 蘑菇王 / 僵尸蘑菇王 / 浮士德 / 多尔 | 30 分钟 |
| 蝙蝠怪 | 3 小时 |

每个 Boss 60 条线。

## 同步原理

- 基于公共 MQTT 服务器（broker.emqx.io）的**保留消息**：最新完整记录作为 retained 消息存在服务器上
- 打开页面即订阅主题，立刻收到最新记录；任何变更会合并后重新发布
- 合并规则：同一条线取时间戳较新的记录；删除用墓碑标记
- 本地 localStorage 自动备份，断网时照常使用，恢复联网后自动补发同步
- 公共服务器不保证长期可靠性，重要记录以本地备份为准

```bash
npm run build    # 构建到 dist/
```
